# Tableau Sales & Customer Dashboard

This folder contains a GitHub Pages portfolio page for a Tableau sales and customer analytics project.

## Live URL after upload
https://othmanxo.github.io/projects/tableau-sales-customer-dashboard/

## Main files
- `index.html`: portfolio project page
- `files/SalesDashboard.pdf`: Tableau dashboard PDF export
- `files/Tableau_Sales_Dashboard_Project.twbx`: packaged Tableau workbook
- `assets/sales-dashboard.png`: Sales Dashboard screenshot
- `assets/customer-dashboard.png`: Customer Dashboard screenshot

## Dashboard views
- Sales Dashboard: total sales, total profit, total quantity, subcategory performance, and sales/profit trends.
- Customer Dashboard: total customers, sales per customer, total orders, customer distribution, and top customers by profit.
