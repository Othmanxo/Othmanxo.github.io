# Power BI & SQL Pizza Sales Analysis

This folder contains a GitHub Pages portfolio page for an end-to-end Power BI + SQL sales analytics project.

## Live URL after upload
https://othmanxo.github.io/projects/powerbi-sql-pizza-sales/

## Main files
- `index.html`: portfolio project page
- `assets/dashboard-preview.png`: visual preview image
- `data/pizza_sales.csv`: source dataset
- `files/PizzaProject.pbit`: Power BI template
- `sql/pizza_sales_queries.sql`: cleaned SQL query file

## Key metrics
- Total revenue: $817,860.05
- Total orders: 21,350
- Total pizzas sold: 49,574
