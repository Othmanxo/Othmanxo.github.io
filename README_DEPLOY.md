# Othmanxo Portfolio Website (GitHub Pages)

This folder contains a multi-page portfolio site (static HTML/CSS/JS) intended to be hosted for free on GitHub Pages.

## Deploy (free)

1. Create a new public GitHub repository named **Othmanxo.github.io** (must match your username).
2. Upload the contents of this folder into the repo root:
   - `index.html`, `projects.html`, `about.html`, `contact.html`
   - `assets/` folder
3. Go to **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. Your site will be live at: https://othmanxo.github.io

## Optional improvements

- Add a resume PDF at the repo root named: `Othman_Alabed_Resume.pdf`
- Add image previews for non-Power BI projects only if needed. The Power BI project uses the PDF export directly.
