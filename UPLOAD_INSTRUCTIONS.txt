HOW TO PASTE THIS INTO YOUR GITHUB PAGES REPOSITORY

1. Download and unzip this file.
2. Copy all files/folders inside `paste_into_repo/` into the root of your `othmanxo.github.io` repository.
3. Allow it to replace/overwrite:
   - index.html
   - projects.html
   - assets/styles.css
4. Keep the new folder:
   - projects/powerbi-sql-pizza-sales/
5. Commit and push:

   git add .
   git commit -m "Add Power BI SQL pizza sales project"
   git push

6. Open:
   https://othmanxo.github.io/projects/powerbi-sql-pizza-sales/

Note: GitHub Pages can take a few minutes to update after pushing.
